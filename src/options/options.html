Ways to save

  • Toolbar button or Alt+Shift+A: edit the title, add a comment, pick tags, color and pin.
  • Right-click a page: "Save page to Anchor" or "Save page with full text to Anchor".
  • Right-click selected text: "Save selection to Anchor" saves it as a quote with the source link.
  • Right-click a link: "Save link to Anchor".
  • Alt+Shift+S: quick save the current page.

You can change keyboard shortcuts in your browser's extension shortcut settings (chrome://extensions/shortcuts or Firefox Add-ons → ⚙ → Manage Extension Shortcuts).
